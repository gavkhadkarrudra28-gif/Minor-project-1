# Minor Project 1 – 4-Bit Binary Adder/Subtractor

## Project Overview

This project presents the design and simulation of a 4-bit binary adder/subtractor circuit using digital logic ICs, SPDT switches, LEDs, resistors, and a breadboard. The circuit is designed to perform both binary addition and subtraction.

## Objective

To design and simulate a 4-bit digital circuit capable of performing binary addition and subtraction using a 4-bit adder and XOR logic gates.

## Components Used

- 74HC283 4-bit Binary Adder IC
- 74HC86 XOR Gate ICs
- SPDT Switches (Slide switches)
- LEDs
- Resistors
- Breadboard
- Arduino Uno
- Jumper Wires
- Tinkercad Circuits

## Working Principle

The 74HC283 is used for 4-bit binary addition, while the 74HC86 XOR gates are used as part of the addition/subtraction logic. SPDT switches provide the required binary inputs and operation control, while LEDs indicate the resulting binary output.

## Simulation

The circuit was designed and simulated using Tinkercad Circuits.
